# Clipboard history panel

Status: approved 2026-11-24. "(call)" marks a decision made by Claude, not the user.

## Intent
Copy things in any app, then open a panel, pick one and paste it where you were writing.
The user asked to "support the copy content" and "have a panel let me paste it", and chose
**A · Quick list** on the artboard. That it is a *history* of copies is an inference the
user has seen and not corrected.

## Goals
- Every text copy is kept, newest first.
- Open, pick and paste without the mouse.
- Kintsugi's own clipboard use never enters the history.

## Non-goals (call)
Images, files, rich formatting, sync, pinned clips, snippets, preview pane, and checking or
explaining a clip from this panel (B and C were not chosen).

## Anti-goals
- Never record what is marked concealed, transient or auto-generated.
- Never send a clip over the network.
- No change to how checking and explaining behave.

## What the user sees
A separate frameless panel, 520×440, with the existing panel's vibrancy, radius and icons.
- Header: focused search field "Search copied text", pause/resume, pin, close. Pause is
  not on the mockup (call).
- Row: one line of text (whitespace collapsed), `App · age`, and ⌘1–⌘9 on the first nine
  visible results.
- Footer: ↩ Paste · ⌘1–9 Paste that one · ⌘⌫ Delete. The mockup said ⌫; plain ⌫ must edit
  the search (call).
- ↑/↓ select; click pastes; Esc closes. Search is a case-insensitive substring match.
- Opens near the mouse with an empty search and the newest clip selected.
- Hides on losing focus unless pinned. A paste hides it; pinned, it shows again after.
- Empty: "Nothing copied yet". No match: "No matches". Paused: says so above the list.
- Without Accessibility, or if the paste fails, the clip goes on the clipboard and the
  panel says to press ⌘V.

Menu bar: "Clipboard History" and "Pause Recording". Settings: shortcut, a recording
switch, and "Clear history…" with a confirmation.

## Defaults (call)
- Shortcut ⌃⌘V. ⌥⌘V is Finder's "move here".
- Recording starts on after updating; CHANGELOG and the README's privacy section say so.
- Keep 200 clips. Skip blank text and text over 100 KB.
- The same exact text moves to the top rather than repeating.
- Clips are stored unencrypted in the existing local database, like checks.
- The clipboard is restored after a paste.

## How
**Native module** (`modules/capture`; edit `capture.go` and Swift, regenerate the rest):
- `ReadClip() (Clip, error)`: text, source app, skip flag. Skip when the clipboard has
  `org.nspasteboard.ConcealedType`, `TransientType` or `AutoGeneratedType`, or when the
  content is Kintsugi's own simulated copy or restore. The module tracks an in-progress
  flag and the change count it last left, under its lock. Types are checked before text
  is read. The source app is the frontmost app, so it is a best guess.
- `FrontApp() (AppInfo, error)`, called before the panel shows.
- `PasteText(text, pid) (WriteResult, error)`: reuses bringToFront,
  waitForModifiersReleased and pasteThroughClipboard. It must not use or change the
  target ReplaceSelection remembers.

**Watching:** `mygo.Clipboard.OnChanged` (macOS polls every 250 ms, so quick successive
copies can merge). Remove the listener while paused. Read and save off the main thread,
one at a time. Text Kintsugi copies on the user's request, such as Copy on a correction,
is recorded.

**Store:** table `clips(id, text UNIQUE, app, copied_at)` with an index on copied_at;
save (upsert, then trim to 200), list, delete, clear.

**Settings:** `clipboardShortcut`, and `recordClipboard` defaulting to true. Existing files
load over `Defaults()`, so they get both. All three shortcuts must differ.
`registerShortcuts` goes from two to three, keeping its rollback.

**UI:** new `clipboard.go` with its own window and state. The checking panel's state stays
separate. Extract only the positioning shared with `showPanel`.

## Visual direction
Product: paste again in a second, mid-sentence. Character: quick, quiet. World: the
existing Kintsugi panel. Moment: the selected row. Signature: none. Use the app's Lobe MyGo
theme tokens; the mockup's colours only approximate them.

## Verification
- Go tests: upsert order, trim, delete, clear; settings defaults and conflicts; filtering.
- `mygo native check`, `go vet`, `go test ./...`, `bun run build`.
- By hand: paste into a native app, a browser and an Electron app; a concealed copy is not
  recorded; checks and replacements add no clips; pause, pin, and no Accessibility.
